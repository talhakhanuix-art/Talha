Download Ready-to-Install Extension (.ZIP)
Quick 30-Second Setup:
  1. Extract the downloaded talha-download-manager-extension.zip.
  2. In Chrome or Edge, open chrome://extensions or edge://extensions.
  3. Turn on Developer mode (toggle in top right corner).
  4. Click Load unpacked and select the extracted folder.
  5. The TDM icon will appear in your browser toolbar ready to capture downloads!
Windows Desktop Installer & Packaging
Standalone Windows 10 & 11 Package

The project is pre-configured with electron-builder to generate a native NSIS Windows .exe installer (TalhaDownloadManager-Setup.exe) and a portable executable.

Download Complete Windows Desktop Source (.ZIP)
Windows Build Commands:
# 1. Install dependencies:
npm install
# 2. Run in live desktop mode:
npm run electron
# 3. Build Windows Setup.exe Installer:
npm run dist:win

The built setup installer will be placed in the dist-electron/ folder, supporting 64-bit Windows 10 and Windows 11.

About Talha Download Manager

Talha Download Manager (TDM)

Version 1.0.0 (Release)

A high-speed Windows desktop download accelerator and manager built with Electron and Node.js. Features chunked range requests, pause & resume, automatic browser capture for Chrome and Edge, video grabbing, and queue scheduling.

Fast. Smart. Always Free. No subscriptions, no ads, no locks.
